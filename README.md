# Electricity Usage Analyzer

A beginner C project that analyzes electricity consumption over 10 days.

## Features

- Calculates total electricity consumption
- Calculates average daily consumption
- Finds the highest consumption
- Finds the lowest consumption

## Concepts Used

- Variables
- Input/Output
- Arithmetic operators
- "if" statements
- "for" loop

## Purpose

This project was created to practice loops and conditional statements in C.
